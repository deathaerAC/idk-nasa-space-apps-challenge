# idk-nasa-space-apps-challenge
moonReport:
    Source:
        LROC QuickMap region exports (the terrain layer is listed as qts_demstack).
    Resolution: 
        each export samples the region on a small grid, so large regions are coarse. Rows with  spacing above 1,500 m are flagged “coarse sample” and should be read as smoothed estimates.
        Hydrogen and iron come from 0.5° maps and describe the surrounding region, not the exact spot.
    Temperature and illumination are still to be added from other layers.
