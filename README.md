# idk-nasa-space-apps-challenge
## Building from source
Clone this repo:
```ps1
  git clone https://github.com/deathaerAC/idk-nasa-space-apps-challenge.git
```
You must have node and a package manager (npm or pnpm) installed. Please install node and a package manager before continuing:
In the cloned directory:
```ps1
  & ./build.ps1
```
